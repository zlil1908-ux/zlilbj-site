# לשים מספרים על החלום · אתר

אתר HTML פשוט, בלי בנייה ובלי תלות בספריות. מתארח ב־Cloudflare Pages.

## מבנה

```
/                     מפנה ל־/workshop/ (בקובץ _redirects)
/workshop/            דף הסדנה
/workshop/thanks/     דף התודה (לכאן שירות הסליקה מחזיר אחרי תשלום)
/terms/               תקנון ותנאי שימוש (טיוטה)
/privacy/             מדיניות פרטיות (טיוטה)
/accessibility/       הצהרת נגישות (טיוטה)
/404.html             עמוד "לא נמצא"
/assets/style.css     קובץ העיצוב המשותף
/assets/main.js       תפריט נגישות, החלפת מחיר, טפסים, הוספה ליומן
/assets/config.js     ההגדרות: מחירים, תאריך, קישורי תשלום, מועדים
```

## הגדרות ב־Cloudflare Pages

- Framework preset: **None**
- Build command: ריק
- Build output directory: `/`

## מה עוד צריך להשלים

1. **קישורי תשלום** ב־`assets/config.js` (`paymentLinks`). עד אז הכפתור מציג הודעה שההרשמה תיפתח בקרוב, עם קישור לוואטסאפ.
2. **כתובת דף התודה** בשירות הסליקה: `https://zlilbj.co.il/workshop/thanks/`
3. **לאן נשלחים פרטי ההרשמה** (מועד, סוג העסק, הסכמה לדיוור): `leadEndpoint` ב־config, או שדות מותאמים בעמוד התשלום.
4. **טופס "אף מועד לא מתאים?"**: `waitlistEndpoint`. עד אז הוא פותח הודעת וואטסאפ מוכנה.
5. **התמונה**: לשמור קובץ בשם `zlil.jpg` בתיקייה `assets` (לאורך, לפחות 720×900). עד אז מוצג איור קטן במקומה.
6. **הטקסטים המשפטיים**: להשלים את תאריכי העדכון, להעביר לעורך דין, ולמחוק את תיבת "טיוטה" בראש כל עמוד.
7. **אם יתווסף כלי סטטיסטיקה או פיקסל פרסום**: לעדכן את סעיף העוגיות במדיניות הפרטיות.

## מדידה

- **Umami** (cloud.umami.is, מסלול Hobby החינמי): את מזהה האתר מכניסים ל־`umamiWebsiteId` ב־`assets/config.js`.
- אירועים שנמדדים: "לחיצה על לשמור מקום" (עם מיקום הכפתור), "שליחת טופס הרשמה", "תשלום הושלם" (כניסה לדף התודה), "טופס מועדים נוספים", "לחיצה על וואטסאפ".
- **קישורים מתויגים**: מוסיפים ל־`_redirects` שורה לכל ערוץ, למשל `/ig  /workshop/?utm_source=instagram&utm_medium=bio  302`.

## בדיקות שימושיות

- `/workshop/?price=late` מציג את הדף כפי שייראה אחרי סוף ההרשמה המוקדמת (399 ₪).
- `/workshop/?price=early` מחזיר את המחיר המוקדם, גם אחרי התאריך.
- מועד שהתמלא: `soldOut: true` ב־config.

## שינוי מועדים

מעדכנים ב־`config.js`, בטקסטים ב־`workshop/index.html`, ובקובצי היומן `workshop/*.ics`.
